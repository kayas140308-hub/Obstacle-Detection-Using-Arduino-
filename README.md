# Obstacle-Detection-Using-Arduino-
🚧 Obstacle Detection Using Arduino

📌 Introduction

The Obstacle Detection Using Arduino project is a simple and low-cost embedded system designed to detect nearby objects using an HC-SR04 Ultrasonic Sensor. The system uses an Arduino UNO to measure the distance between the sensor and an obstacle.

When an object comes within a predefined distance, an LED and buzzer provide visual and audible alerts. This project demonstrates the practical application of Arduino programming, sensor interfacing, and real-time obstacle detection.

🎯 Main Objective: To develop an affordable obstacle detection system that can be used in robotics, automation, and safety applications.

✨ Key Features

- 📡 Ultrasonic distance measurement
- 🚨 Automatic obstacle alerts
- 💡 LED visual indication
- 🔊 Buzzer sound alert
- 🤖 Arduino-based control system

Technologies Used: Arduino UNO · HC-SR04 Ultrasonic Sensor · Embedded C/C++
